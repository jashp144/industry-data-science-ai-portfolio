# CloudCommerce Security & Data Protection Standards

All customer data at rest is encrypted using AES-256 GCM encryption.
All data in transit is protected using TLS 1.3 with automated certificate rotation.
The platform maintains SOC 2 Type II, ISO 27001, and GDPR compliance certifications.
Access to production databases requires hardware MFA and just-in-time (JIT) role elevation.
Automated vulnerability scans run daily, and third-party penetration testing is conducted biannually.
